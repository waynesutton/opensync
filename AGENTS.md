When working on Convex code, **always read

how to correctly use Convex APIs and patterns. The file contains rules that

`npx convex ai-files install`.

## OpenSync design rules

Read [design.md](design.md) before any frontend, dashboard, leaderboard, chart or graph work. Never add decorative eyebrow/kicker/overline text above headings. Start with the actual heading; a short supporting sentence below is allowed. Preserve functional field labels, chart axes, legends, units and table headers. Use the shared typography in `src/styles/typography.css`; keep light/dark themes consistent. These owner-specific rules override generic design-skill examples.
