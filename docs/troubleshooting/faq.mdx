# Frequently asked questions

## Where does OpenSync run?

The hosted frontend uses Convex static hosting. Convex also runs the backend and database; WorkOS handles sign-in. The separate documentation site is published with Mintlify. See [static hosting](/hosting/static-hosting).

## Which URL do I enter in a plugin?

Use `https://api.opensync.dev` with clients that support custom HTTP domains. Current OpenCode 0.3.7 and Claude Code 0.1.15 login commands require the compatibility URL from Settings. Keep existing working configurations. See [hosted setup](/getting-started/hosted).

## Does everyone appear on the leaderboard?

No. Participation is off by default. Opting in shares your chosen first name, token total, rank and top model. It does not share email or session content. Turn participation off in Settings → Profile to leave. See [usage leaderboard](/dashboard/usage-leaderboard).

## Are token totals the same as my current context size?

No. Context size describes one request's context window. Recorded usage can span multiple requests and includes the values reported by plugins. It is not a verified bill or subscription-quota reading. Historical indexing and plugin limitations can affect totals.

## Can I move to my own deployment?

Create your own Convex and WorkOS setup and point your plugins at that instance. Existing working plugin configurations do not move automatically. CSV and session exports are available, but a complete account migration/import is not automated. Retain source data and check plugin backfill compatibility before relying on a resync.

## Can I delete my data?

Settings → Profile includes data and account deletion controls with background progress. If deletion fails, capture the request ID and report it without sharing private content. Do not delete an entire Convex deployment as a routine account-cleanup step. See [common issues](/troubleshooting/common-issues).

## Are teams available?

Team membership and team administration remain planned. The current owner console is restricted to platform owners; it does not grant team-admin access.

## How do I report a problem?

Search the [existing issues](https://github.com/waynesutton/opensync/issues) first. Include the plugin version, source-tool version, OS, reproduction steps and exact error. Remove API keys, callback codes and private session content.
