# Usage leaderboard

The [public usage leaderboard](https://www.opensync.dev/usage-leaderboard) shows people who choose to participate.

## Join or leave

1. Sign in and open **Settings → Profile**.
2. Review your public first name and enable the public leaderboard checkbox.
3. Use **View public leaderboard** to see the board. You can also open **Leaderboard** from the dashboard beside Wrapped.
4. Turn the preference off to leave the public board.

Participation is off by default. Opting in publishes your first name, token total, ranking and top model. It does not publish your email, prompts, code, session contents or private account identifiers. Session sharing is a separate setting.

## Browse the board

The first page shows up to 100 entries. Use **Load more** for the next 100. Sorting and the exact top-model filter apply across the matching results, not just the rows already loaded. Changing the filter or sort starts a new result set.

Ranking reflects recorded token usage, not skill, model quality, billing or remaining subscription quota. Historical indexing can leave totals incomplete; the page displays its indexing status when applicable.
